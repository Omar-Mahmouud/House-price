Project Overview:
A machine learning and data science project centered on India's residential real estate market — exploring what drives property prices and building regression models to predict them from cleaned, structured data,
The core of this repository is a Jupyter Notebook  that walks through a full data science workflow, from raw and messy real estate data to a working predictive model. Along the way, it tackles the usual pain points of real-world housing datasets: missing values, inconsistently formatted text fields, and heavily skewed price distributions.
Key Objectives
Exploratory Data Analysis — Investigate which numerical and categorical features most influence property prices, including Carpet Area, Location, and Furnishing status.
Data Cleaning & Preprocessing — Address columns with high rates of missing data, parse out numeric values from messy string fields like Carpet Area, and assemble reusable preprocessing pipelines.
Modeling & Evaluation — Transform features into a model-ready format using StandardScaler and OneHotEncoder, then train and compare algorithms including DecisionTreeRegressor and RandomForestRegressor.
